| Camera colour matrices | `fos_dev.c` per `CONFIG_<camera>` from LibRaw `colordata.cpp` | Pattern reusable; SX510 HS values must come from the DNG / LibRaw. |
| JPEG writer | `fos_jpeg.c` (397 lines) | **Likely portable** (uses `fos_port_alloc`). Evaluate for CHDK offline output in P05. |
| UI (shelf, HUD, pages), fonts | `fos_ui.c`, `fos_shelf.c`, … 720×480 8-bit canvas via `fos_port_*` | Reusable for P04 only if the CHDK bitmap/palette allows; HARDWARE-TEST REQUIRED. |

### CHDK (`vendor/chdk-trunk`)

- **VERIFIED** License: GPL (`COPYING`, `doc/5_gpl.txt`).
- **VERIFIED** `camera_list.csv`: `sx510hs` firmwares `100a`, `100c`, `100d`, `101a`, all **ALPHA** (100a/100c reuse 100d).
- **VERIFIED** `platform/sx510hs/notes.txt`: tested *Remote capture* and *Liveview*; **known bug: "DNG color matrix is copy+paste from D10"** → camera DNG colour metadata is untrustworthy; P02 must calibrate SX510 HS colour (LibRaw matrix or own gray-card measurement) and not trust `ColorMatrix1` blindly.
- **VERIFIED** `platform_camera.h`: `CAM_RAW_ROWPIX 4168`, `CAM_RAW_ROWS 3062` (sensor buffer; active area to be read from real DNGs), `CAM_HAS_WIFI 1`.
- HARDWARE-TEST REQUIRED: which firmware the owner's camera runs, whether the build boots, actual DNG active area, free RAM, Wi-Fi.

### Toolchain gaps

- No ARM cross-compiler (`arm-none-eabi-gcc`) installed → device-side builds not attempted (P04/P05).
- `rawpy` / LibRaw dev packages not installed → needed for P02 Linux DNG input adapter.
- No JPEG library (`libjpeg`) dev package via pkg-config → choose between `fos_jpeg.c` and libjpeg-turbo in P02.

## Constraints and follow-up

- What cannot yet be claimed: no DNG is decoded, no image is developed by this repo, no JPEG is produced, nothing has run on a camera. The tile renderer (`mf_core_process_tile`) returns `MF_E_UNSUPPORTED`. Importer checks only TIFF magic, not DNG structure.
- Risks: upstream M-Film is very young and changes daily (pin moved on the day of audit); grain/halation are tuned for a 720×480 8-bit print, so scaling them to 4000×3000 is a modelling decision that must be validated visually; SX510 HS DNG colour matrix is known-wrong in CHDK.
- Next implementation tasks:
  1. P01: profile bundle generator from `films/films.py` (all 72 looks), bundle hash, `mf_look_find` over bundle.
  2. P01: port vignette/halation/grain to float, resolution-independent tile stages; golden tests at 720×480 against upstream `stage_finish`.
  3. P02: install LibRaw/rawpy; `mfilm-develop` CLI (DNG → linear sRGB → `mf_core` → JPEG 4000×3000) with provenance sidecar.
  4. P03: worker + job queue over the existing catalog; PhotoPrism publisher; systemd units; `config.example.toml`.
- Owner action needed: Canon firmware version of the SX510 HS (Menu → firmware, or CHDK `ver.req`), and 2–3 sample CHDK DNGs (daylight, gray card, tungsten) — only when P02 reaches real-camera calibration.
